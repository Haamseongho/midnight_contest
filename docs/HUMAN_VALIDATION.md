# 실제 사람 검수 — 아직 미실시

자동 DOM·회로·네트워크 테스트로 아래 사람의 경험을 대체하지 않는다. 신규 방문자 3명과 실제 발표자의 응답/측정이 들어오기 전에는 체크하지 않는다. 이름·지갑·비밀값·녹음은 수집하지 않고 P1/P2/P3로 기록한다.

## 신규 방문자 3명 이해도

공개 데모의 첫 화면과 확인자 전용 화면을 보여주고, 답을 먼저 알려주지 않은 상태에서 질문한다.

1. 이 서비스는 누구의 어떤 문제를 해결하나요?
2. 비밀값을 입력하고 거래를 승인하는 사람은 누구인가요?
3. 확인자에게 지갑이나 비밀값이 필요한가요?
4. ‘사용 기록 있음’이 지금 온 사람의 입장 승인인가요?
5. 과거 거래 카드·방금 조회·로컬 회로 시연의 차이를 설명해 주세요.

정답 기준: 초대 비밀을 공개하지 않는 소비 확인 / 소지자 자기 환경 / 불필요 / 승인 아님 / 과거 거래·현재 공개 상태·체인 아닌 로컬 실행 구분. 한 항목이라도 혼동하면 해당 문구와 경로를 수정하고 다시 확인한다. 3명 모두 모든 핵심 경계를 설명하면 통과로 기록한다(제안된 프로젝트 검수 기준, 대회 공식 기준 아님).

## 실제 30초 / 3분 낭독
